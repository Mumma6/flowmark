---
title: createFlowmarkProxy
description: Receive browser telemetry through an authorized same-origin server route.
---

## Imports and signature

```ts
import { createFlowmarkProxy } from "@flowmark/node/proxy"
// Also exported from "@flowmark/node/next/proxy".

// createFlowmarkProxy(config?: FlowmarkProxyConfig):
//   (request: Request) => Promise<Response>
```

This is a Web Request/Response handler, not a Next.js-only wrapper.

## Example

```ts
// app/api/flowmark/route.ts
import { createFlowmarkProxy } from "@flowmark/node/next/proxy"

export const POST = createFlowmarkProxy({
  authorize: async (request) => await canRecordWorkflow(request),
})
```

`canRecordWorkflow` is your application's authentication/rate-limit check;
Flowmark does not supply it. The browser uses
`createFlowmark({ proxyPath: "/api/flowmark" })` from the browser entry.

## Options

| Field       | Meaning                                                      |
| ----------- | ------------------------------------------------------------ |
| `apiKey`    | Private server-write key; defaults to `FLOWMARK_API_KEY`     |
| `apiUrl`    | API origin; defaults follow server configuration             |
| `authorize` | Optional `(request: Request) => boolean \| Promise<boolean>` |

Authorization runs before body parsing. Add it before exposing the route;
same-origin checks are not authentication or rate limiting. `false` denies the
request. Thrown authorization errors are logged and return 502.

## Request and response behavior

The handler requires POST, a matching Origin, and no cross-site Fetch Metadata.
It validates the event envelope and bounds streamed bodies to 64 KiB. It adds
the server's key and sends to private `/v1/events`.

| Status    | Meaning                                                     |
| --------- | ----------------------------------------------------------- |
| 202       | Upstream accepted the event                                 |
| 400       | Invalid envelope/body or upstream validation rejection      |
| 403       | Method/origin/access check rejected                         |
| 409 / 429 | Upstream conflict / throttling                              |
| 502       | Configuration, authorization exception, or delivery failure |

Private-route forwarding does not make browser reports trustworthy. Do not use
them as proof of payments or business identity.
