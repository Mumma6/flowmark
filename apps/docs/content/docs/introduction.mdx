Mark a process in TypeScript. See its volume, duration, success rate, and
the result each execution reported.

```ts
const run = flowmark.workflow("invoice.import", { properties: { batchId } })
run.step("source-loaded", { properties: { count: 1000 } })
run.done({ result: { imported: 988, skipped: 12 } })
```

This is an instrumentation sketch. The [quickstart](/docs/sdk) shows where
the markers belong around real work, including failure handling and delivery.

## Install

```bash
npm i @flowmarkdev/node
```

Then open the [quickstart](/docs/sdk) to create a client and mark a process.

## Insights you can use

- **Volume:** how often a process runs, including daily counts for 30 days.
- **Outcomes:** success rate among finished runs, plus failed-run count.
- **Performance:** median duration from start to `done()` or `fail()`, and
  per-operation timing on the timeline.
- **Progress:** the last reported snapshot, such as 600 of 1,000 records.
- **Result:** the business summary your code attached — imported, skipped,
  shipped, paid.

A completed import can still have skipped records. A failed order can already
have captured a payment. Those facts sit on the same execution.
