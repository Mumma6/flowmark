---
title: Save and share investigations
description: Keep live questions, share them with authorized colleagues and distinguish captures from exports.
---

An investigation saves the question and selection you want to revisit. It does
not create a dashboard, copy all telemetry or grant another person access.

## Save a private question

Use **Save this live investigation** on a supported selection. Give it a useful
name, then reopen it from **Investigations** in the same project. Private
questions belong to your account. Reopening reads current authorized evidence;
source deletion, changed permissions or publication can make it unavailable.

Comparison windows saved as absolute dates stay absolute. A relative peer-day
selection remains live. A changed result is not necessarily a changed saved
question. Inspect the displayed population and coverage.

## Share with the project

From a private entry, prepare a shared copy, review its title, evidence depth and
audience, then confirm. Business evidence also offers **Share live question**.
The recipient must sign in and already belong to the selected project. Sharing a
link neither invites them nor grants permission; use
[Project access](/docs/project-access) to manage membership.

- **Diagnostic depth:** available to current owners and diagnostic viewers.
- **Business depth:** uses only currently published business evidence, including
  when an owner opens it. Unsupported filters or selections remain explicit.

The shared question is an immutable copy. Its private original remains private;
deleting that original does not remove the shared copy. The creator or project
owner can revoke the copy without deleting source telemetry. A saved continuation
cursor cannot be shared; return to the first page and save the supported question.

## Captures and portable views

A live question recomputes. A captured business projection represents bounded
supplied evidence and has its own expiry and access checks. Source implementation
does not mean hosted capture admission or physical cleanup is enabled. Do not rely
on a hosted capture workflow unless that environment has activated it.

A [portable snapshot](/docs/portable-evidence) is another limited presentation,
not an account/project export. Once a file has been downloaded, Flowmark cannot
recall that copy or prove the recipient's current access.

## When evidence is unavailable

Check the project selection, current membership, owner publication and source
lifetime. Revocation, expiry and source deletion should not be treated as an
empty successful result. Refresh a failed read; do not automatically recreate a
shared object or remove filters. See [troubleshooting](/docs/troubleshooting).
